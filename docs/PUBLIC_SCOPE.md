# Public Scope and Sanitization

The original archive was not suitable for direct publication.

Removed from the public package:

- environment files containing database, session/JWT and AI-provider credentials;
- test account passwords and admin credentials;
- temporary Cloudflare/Replit deployment links and operational notes;
- real-organization seed data including organization identifiers;
- official challenge documents and 1C `.cf` / `.cfe` files;
- internal status reports, PR drafts and claims such as “100%” or “Production Ready”;
- failed deployment screenshots and other debug artifacts.

The resulting repository is intentionally a **portfolio case study with representative code samples**, not an archival dump of the original submission.
